# PS Archive Manager (Tauri)

برنامه ویندوزی برای فهرست‌کردن آرشیو PS4/PS5. بررسی آنلاین (اسم بازی و آخرین نسخه آپدیت) با یک پنجره مرورگر واقعی (WebView2) انجام می‌شود. برنامه هیچ فایل اصلی را حذف، کپی یا جابه‌جا نمی‌کند. برای فایل‌های شناسایی‌شده می‌تواند پوشه بازی و شورتکات ویندوزی بسازد.

## ساخت فایل نصب با GitHub Actions (یک‌بار)
1. در github.com یک مخزن (repository) جدید بسازید (خصوصی هم مشکلی ندارد).
2. همه فایل‌های این پوشه را، **از جمله پوشه `.github`**، در مخزن آپلود کنید (با Git یا «Add file → Upload files»).
3. تب **Actions** → «Build Windows app» → **Run workflow**.
4. بعد از حدود ۱۰ دقیقه، همان صفحه را باز کنید و در بخش **Artifacts** فایل `PS-Archive-Manager-windows` را دانلود کنید. داخلش فایل نصب (`...setup.exe`) است. نصب روی ویندوز نیاز به دسترسی ادمین ندارد.

## استفاده
- «انتخاب پوشه آرشیو» → پوشه را از پنجره انتخاب پوشه ویندوز انتخاب کنید؛ سپس فایل‌های پشتیبانی‌شده اسکن می‌شوند.
- اگر گزینه ساخت شورتکات فعال باشد، برای هر فایل دارای نام بازی یک میانبر `.lnk` در مسیر `PS Archive Shortcuts\نام بازی` ساخته می‌شود. میانبر به فایل اصلی اشاره می‌کند؛ فایل اصلی سر جای خودش می‌ماند.
- برای حذف فایل اصلی از ویندوز، روی شورتکات راست‌کلیک کنید و «Open file location» را بزنید؛ حذف خود شورتکات فقط لینک را حذف می‌کند، نه فایل اصلی.
- بررسی آنلاین خودکار بعد از اسکن شروع می‌شود.
- اگر سایت «تأیید انسانی» (Cloudflare) خواست، یک پنجره باز می‌شود؛ یک‌بار انجامش دهید و پنجره خودش بسته می‌شود.
- اگر بررسی آنلاین ۳ بار پشت‌سرهم ناموفق شد، پایین صفحه «گزارش عیب‌یابی» پر می‌شود؛ آن را برای توسعه‌دهنده بفرستید.

## تغییرات نسخه 1.3.0
- ترتیب بررسی آنلاین: خود سایت (WebView، اسم + نسخه‌ها) ← Serper ← Google. نتیجه API فقط وقتی پذیرفته می‌شود که لینکش از همان سایت (ORBIS/PROSPERO) باشد و Title ID دقیقاً در آن بیاید؛ وگرنه «ambiguous» و می‌رود صف بررسی.
- تشخیص سهمیه بر اساس کد HTTP و فیلدهای ساختاریافته خطا (نه regex روی کل متن)؛ خطای شبکه/CORS و کلید نامعتبر جدا گزارش می‌شوند.
- تنظیم «Provider» دیگر خودکار تغییر/ذخیره نمی‌شود؛ جابه‌جایی فقط برای همان اجرا است.
- حلقه با «سهمیه/کلید همه سرویس‌ها تمام شد» یا ۳ خطای پشت‌سرهم متوقف می‌شود و پنجره تنظیمات فقط یک‌بار باز می‌شود.
- پنجره تنظیمات فقط وقتی خودکار باز می‌شود که حالت Serper یا Google انتخاب شده و کلیدش ناقص است.
- شورتکات فقط برای اسم‌های قابل‌اعتماد ساخته می‌شود (از سایت، ویرایش دستی، یا ردیف تأییدشده).
- Rust: حذف پیشوند `\\?\` ویندوز از مسیرها (برای .lnk و explorer)، فایل `.psa-index.json` برای جلوگیری از برخورد شورتکات‌های هم‌نام، رعایت محدودیت ۲۶۰ کاراکتری مسیر، و اسکن پوشه خارج از ترد async.
